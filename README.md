# PoE 액트 목표 가이드 오버레이

Path of Exile 1 캠페인(1~10장)을 진행하는 동안 **지금 액트에서 꼭 해야 할 일**을 게임 화면 위에 띄워 주는 Windows 오버레이.

| | |
|---|---|
| 대상 게임 | Path of Exile **1** (한국어 카카오 클라이언트 기준, 영문 클라이언트도 동작) |
| 플랫폼 | Windows 10/11 · .NET 8 · WPF |
| 진행 감지 | 게임 로그 `Client.txt` / `KakaoClient.txt` 자동 감지 |
| 용도 | 개인용 로컬 빌드 |

## 보여 주는 것

현재 액트의 목표를 다섯 갈래로 묶어 보여 준다. 지금 서 있는 지역에서 할 일은 **노란 굵은 글씨**로 강조한다.

| 섹션 | 내용 | 예 |
|---|---|---|
| **진행** | 액트의 큰 줄기 — "~에서 ~ 처치" | 황혼의 해안에서 힐록 처치 |
| **전직** | 전직 시험 위치와 미궁 시점 | 수용소 하층 전직 시험 · 시험 6개 완료 → 일반 미궁 |
| **패시브 포인트** | 패시브 포인트를 주는 퀘스트 — "~에서 ~ 처치" | 물에 잠긴 심연에서 심연의 주인 처치 |
| **조합법** | 레벨링에 쓸 제작대 조합법을 얻는 지역 | 광산 1층: 소켓 색상 변경 ★ |
| **유용한 퀘스트** | 진행을 편하게 해 주는 퀘스트 | 도서관 → 문서 보관소에서 황금 책자 4장 (시오사) |

★ 표시는 특히 중요한 항목(소켓·이동 속도 조합법, 미궁, 키타바 저항 감소 등)이다.

```
3장                                       하수도 · Lv 26
진행
 • 사안 시내에서 클라리사 구출
 • 하수도 장애물을 태우고 칠흑의 군단 주둔지에서 그라비시우스 장군 처치   ← 현재 지역이면 강조
패시브 포인트
 • 하수도에서 백금 흉상 3개 획득
   보상: 하간 (빅타리오의 비밀)
조합법
 ★ 사안 시내: 이동 속도 1단계
 • 하수도: 물리 피해 1단계
...
```

## 진행 감지 방식

게임은 지역에 들어갈 때마다 로그에 다음 줄을 남긴다.

```
2024/12/01 20:15:03 ... [DEBUG Client 1234] Generating level 2 area "1_1_2" with seed 2914721377
```

이 줄의 지역 ID(`1_1_2`)는 **클라이언트 언어와 무관**하므로, 한국어 클라이언트의 "~에 진입했습니다" 문구 대신 이것으로 현재 지역과 액트를 판단한다. 시작할 때는 기존 로그 끝부분에서 마지막 지역을 찾아 바로 그 액트를 띄운다.

- 로그 위치: 실행 중인 게임 프로세스의 폴더 → 흔한 설치 경로(카카오/Daum, GGG, Steam) 순으로 `logs\KakaoClient.txt`, `logs\Client.txt`를 찾는다. 못 찾으면 5초마다 다시 찾고, 트레이 메뉴에서 직접 지정할 수 있다.
- 은신처·미궁처럼 가이드에 없는 지역에 들어가면 액트를 바꾸지 않는다. 지망자의 광장(미궁 입구)은 3장 지역이지만 4·7·10장에서도 들르므로 역시 액트를 바꾸지 않는다.
- 핫키로 다른 액트를 미리 볼 수 있다(헤더에 "수동 선택" 표시). 다음 지역 이동 시 자동 감지로 돌아간다.

## 사용법

게임은 **창 모드 전체 화면(테두리 없는 창)** 으로 실행해야 한다. 전용 전체 화면에서는 어떤 오버레이도 보이지 않는다.

오버레이는 클릭을 받지 않는다(클릭이 전부 게임으로 통과). 조작은 핫키와 트레이 아이콘으로 한다.

| 기본 핫키 | 동작 |
|---|---|
| `Ctrl+Shift+G` | 오버레이 보이기/숨기기 |
| `Ctrl+Shift+PageUp` / `PageDown` | 이전 / 다음 액트 보기 |
| `Ctrl+Shift+C` | 간단히 보기 (진행 + 현재 지역 + ★ 항목만) |
| `Ctrl+Shift+M` | 위치 이동 모드 — 켜는 동안 마우스로 드래그해 옮기고, 끄면 위치가 저장된다 |

트레이 아이콘(작업 표시줄 오른쪽)에는 위 기능과 함께 *로그 파일 지정*, *설정 파일 열기*, *가이드 데이터 폴더 열기*, *종료*가 있다.

### 설정

`%APPDATA%\PoeActGuide\settings.json` — 트레이 메뉴의 *설정 파일 열기*로 연다. 고친 뒤 앱을 다시 시작하면 적용된다.

| 키 | 기본값 | 설명 |
|---|---|---|
| `clientLogPath` | `null` | 로그 파일 경로. 비우면 자동 감지 |
| `left`, `top`, `width` | 20, 160, 400 | 위치와 너비 (높이는 내용에 맞춤) |
| `backgroundOpacity` | 0.78 | 배경 불투명도 0.2~1 (글자는 항상 불투명) |
| `fontSize` | 13 | 글자 크기 |
| `compact` | false | 간단히 보기 |
| `hotkeys.*` | 위 표 | `"Ctrl+Alt+F5"` 형식. 빈 문자열이면 끔 |

## 빌드 · 실행

필요한 것: **.NET 8 SDK**, Windows.

```powershell
dotnet run --project src/PoeActGuide.App            # 실행
dotnet test                                          # 테스트 (Core만 대상, Linux에서도 실행 가능)
dotnet publish src/PoeActGuide.App -c Release -r win-x64 --self-contained false -o publish
```

`publish\PoeActGuide.exe`를 실행하면 된다. 가이드 데이터는 exe 옆 `Data\` 폴더에 복사되므로 다시 빌드하지 않고 고쳐 쓸 수 있다.

## 구조

```
data/                       가이드 데이터 (exe 옆 Data\ 로 복사됨)
  guide.ko.json               액트별 목표 — 손으로 작성
  areas.ko.json               지역 ID → 한국어 이름/액트/레벨 — tools/build_areas.py 로 생성
src/PoeActGuide.Core/       플랫폼 무관 로직 (net8.0)
  Guide/                      데이터 모델 · 로더 · 검증기
  Log/                        Client.txt 파싱 · 이어 읽기 · 위치 찾기
  Progress/                   현재 지역 → 표시할 목표 계산
  Settings/                   설정 · 핫키 파싱
src/PoeActGuide.App/        WPF 오버레이 · 전역 핫키 · 트레이 아이콘 (net8.0-windows)
tests/PoeActGuide.Core.Tests/   xUnit
tools/build_areas.py        지역 표 생성기
```

가이드 내용을 고치거나 늘리는 방법은 [`docs/DATA.md`](docs/DATA.md)를 본다.

## 확인이 필요한 것

이 저장소의 코드는 Linux에서 컴파일과 Core 테스트까지만 확인했다. **Windows에서 실제 게임과 함께 띄워 본 적은 아직 없다.** 처음 실행할 때 다음을 확인해야 한다.

- 카카오 클라이언트 로그 파일 이름이 `KakaoClient.txt`이고, 거기에도 `Generating level ... area "..."` 줄이 찍히는지
- 오버레이가 테두리 없는 창 모드 게임 위에 계속 떠 있는지, 클릭이 게임으로 통과하는지
- 기본 핫키가 게임 키 설정과 겹치지 않는지

가이드 내용 중 아래는 공개 데이터를 옮긴 것이라 패치에 따라 달라질 수 있다 ([`docs/DATA.md`](docs/DATA.md) 출처 참조).

- 조합법 획득 지역 (리그마다 바뀐 적이 있다)
- 도적 처리 "모두 처치" 보상 포인트 수 — 표시 문구에는 숫자를 넣지 않았다
- 자비로운 임무 완료 후 네사의 퀵실버 플라스크 판매
