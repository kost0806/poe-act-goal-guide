# PoE 액트 목표 가이드 — working notes

- Build: `dotnet build` (the WPF app compiles on Linux thanks to `EnableWindowsTargeting`, but only runs on Windows).
- Test: `dotnet test` — Core only. Warnings are errors.
- Keep it simple: Core (`net8.0`) holds every piece of logic that can be tested; the App project is thin WPF/Win32 glue.
- Guide content is the levelling route, step by step in order: `data/guide.ko.json` (hand-written; Korean client terms only — a test rejects Latin letters) and `data/areas.ko.json` (generated by `tools/build_areas.py` — regenerate, don't hand-edit). Format and sources: `docs/DATA.md`.
- A step's `areas` drive automatic progress (4-step lookahead, towns 1 step): list where the step is done, not corridors you pass through. Replay a whole run when changing them.
- Area detection uses the untranslated `Generating level N area "<ID>"` log line, never the localized "entered" message.
- When a fact in the guide comes from memory rather than a source in `docs/DATA.md`, say so in the README's "확인이 필요한 것" list.
